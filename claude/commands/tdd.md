# TDD 워크플로우 커맨드

테스트를 먼저 작성하고, 테스트를 통과하는 코드를 구현합니다.

## 실행 단계

### 1단계: 요구사항 파악

$ARGUMENTS 에서 구현할 feature를 파악합니다.
CLAUDE.md와 가장 관련 있는 기존 컴포넌트 1개를 읽어 패턴을 확인합니다.

요구사항이 모호하거나 테스트 범위가 불명확하면 **AskUserQuestion**으로 확인합니다:
- 어떤 케이스를 테스트해야 하는지
- 엣지 케이스 범위 (에러 처리, 빈 값 등)
- 단위 테스트 vs 통합 테스트 선호

### 2단계: 병렬 에이전트 실행

Task tool로 2개의 sub-agent를 실행합니다.

#### Agent 1: 테스트 작성

- 요구사항을 테스트 케이스로 변환
- 기존 테스트 파일의 패턴을 따름
- 실패하는 테스트를 먼저 작성

#### Agent 2: 구현

- Agent 1이 작성한 테스트를 통과하는 최소한의 코드 구현
- 기존 feature 모듈 구조를 따름
- 테스트가 모두 통과하면 리팩토링

### 3단계: 검증

테스트를 실행하여 모두 통과하는지 확인합니다.
실패하는 테스트가 있으면 수정 후 재실행합니다.
