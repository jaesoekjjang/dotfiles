# UI/UX 셀프 평가 및 반복 개선

대상 컴포넌트/페이지를 4개 카테고리로 엄격하게 평가하고, 통과할 때까지 자동으로 개선합니다.

## 평가 기준 (각 10점 만점, 총 40점)

### 1. 정보 구조 & 인지 흐름 (Information Architecture)

> "사용자가 무엇을 해야 하는지 3초 안에 이해 가능한가?"

- Primary Action이 1개로 명확한가
- 정보 우선순위가 시각적으로 구분되는가 (size, weight, spacing)
- 스크롤 없이 핵심 정보 이해 가능한가
- 상단 영역(hero/header)의 목적이 명확한가
- 탭/필터/네비게이션 구조가 혼동되지 않는가

| 점수 | 기준 |
|------|------|
| 0-3 | 목적 불명확, CTA 2개 이상 경쟁 |
| 4-6 | 이해 가능하지만 정보 밀도 과다 |
| 7-8 | 명확하지만 소폭 개선 여지 |
| 9-10 | 한눈에 흐름 파악 가능 |

### 2. 시각적 계층 구조 (Visual Hierarchy)

> "눈이 어디부터 어디로 이동해야 하는지 명확한가?"

- 제목 > 서브텍스트 > 보조정보의 대비 비율이 적절한가
- font size scale이 일정한가
- 같은 레벨 요소는 동일 스타일인가
- 강조 색상은 전체 화면의 10~15% 이하인가

**감점 규칙:**
- 텍스트 사이즈 종류 5개 초과 → -2점
- accent color가 버튼 외에 과도 사용 → -2점

### 3. 인터랙션 일관성 (Interaction Consistency)

> "버튼/토글/세그먼트의 의미가 화면마다 동일한가?"

- ghost / primary / destructive 버튼 의미가 일관적인가
- 클릭 영역이 최소 44px 이상인가
- modal / sheet / page 전환 기준이 명확한가
- hover/active 상태가 존재하는가

### 4. 인지 부하 & 정보 밀도 (Cognitive Load)

> "사용자가 생각해야 할 것이 너무 많은가?"

- 한 화면 내 선택지 7개 초과 여부
- 아이콘 + 텍스트 중복 여부
- 필터 옵션이 과도한가

**구조 실패 판정:**
- 동일 화면에서 탭 + 세그먼트 + 필터 + 토글 중 3종류 이상 동시 존재 → 해당 카테고리 0점

## 실행 프로세스

### 통과 기준

- 각 카테고리 **8점 이상** AND 총점 **34점 이상**
- 최대 반복 **3회**

### 1단계: 대상 파일 읽기

$ARGUMENTS 에서 대상 컴포넌트/페이지 파일을 읽습니다.
프로젝트에 디자인 가이드가 있으면 함께 읽습니다.

### 2단계: 평가 및 Scoring

각 카테고리를 평가하고 다음 형식으로 출력합니다:

```
## 평가 결과 (Round N/3)

| 카테고리 | 점수 | 주요 문제 |
|----------|------|-----------|
| 정보 구조 | ?/10 | ... |
| 시각적 계층 | ?/10 | ... |
| 인터랙션 일관성 | ?/10 | ... |
| 인지 부하 | ?/10 | ... |
| **총점** | **?/40** | |

### 감점 상세
- [카테고리] 파일:라인 — 문제 설명 (분류: layout | hierarchy | interaction)
```

### 3단계: 개선

통과 기준 미달 시:

1. 각 문제를 **layout / hierarchy / interaction** 중 하나로 분류
2. 개선 방향이 여러 가지일 떄, 트레이드오프가 있으면 **AskUserQuestion**으로 사용자에게 확인:
   - 정보 밀도를 줄일지 vs 레이아웃을 재구성할지
   - 어떤 요소를 Primary Action으로 유지할지
   - 시각적 위계에서 무엇을 가장 강조할지
3. 분류별 개선안을 생성하고 코드에 적용
4. 2단계로 돌아가 다시 scoring

### 4단계: 종료

- **통과**: 최종 점수와 개선 이력을 출력
- **3회 미통과**: 현재 상태의 점수와 남은 미달 항목을 리포트하고, 사용자에게 판단 위임

```
## 최종 리포트

### 개선 이력
| Round | 총점 | 변경 사항 |
|-------|------|-----------|
| 1 | ?/40 | ... |
| 2 | ?/40 | ... |
| 3 | ?/40 | ... |

### 미달 항목 (사용자 판단 필요)
- ...
```
