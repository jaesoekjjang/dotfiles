# Obsidian Vault Maintenance (n8n)

n8n cron으로 Obsidian vault를 주기적으로 관리하는 워크플로우 계획.

## A. 구조/정리 (셸 스크립트)

### 높은 가치
- **Inbox 방치 노트 감지**: N일 이상 inbox에 머문 노트 알림
- **Orphan 노트 탐지**: 어디서도 링크되지 않은 노트 목록
- **Broken link 탐지**: `[[존재하지 않는 노트]]` 찾기

### 보통 가치
- **태그 정규화**: 불일치 태그 리포트 (자동 수정은 위험 → 리포트만)
- **중복/연관 노트 감지**: AI 필요, 비용 발생

### 낮은 가치 (사람 판단 필요)
- **PARA 최신화**: 어디로 옮길지는 결국 사람 판단
- **품질 개선**: 자동으로 남의 노트 고치면 위험

## B. 콘텐츠/리뷰 (AI 필요)

### 높은 가치
- **미완료 TODO 리마인더**: `- [ ]` grep → Hammerspoon 알림
- **주간 리뷰 서머리**: 최근 수정 파일 모아서 AI 요약

### 낮은 가치
- **노트 자동 요약/채우기**: 의도치 않은 변경 위험

## 추천 1차 워크플로우: Vault Health Report

매일 아침 cron으로 스캔 → Hammerspoon 알림 or 리포트.md 생성:

1. Inbox에 N일 이상 방치된 노트 수
2. Orphan 노트 목록
3. Broken link 목록
4. 미완료 TODO 수

자동 "수정"보다 자동 "감지 + 알림"이 안전하고 실용적.
